# Axiolock

A Python library for algebraic compilation based on axioms

Requires Python 3.11 or newer.

## Installation

```bash
python -m pip install axiolock
```

To install the development dependencies, run:

```bash
python -m pip install -e ".[dev]"
```

## Verification

```bash
python -m pytest
python -m ruff check .
python -m build
```
